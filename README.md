## Microsoft Windows Server | Active Directory | PowerShell | Enterprise Administration

**Status:** Active Development

# Overview

This repository documents the practical development of Microsoft infrastructure administration skills through structured laboratory exercises.

Following the completion of the identity foundation phase, this repository expands into the infrastructure layer that supports modern Microsoft enterprise environments.

The objective is to develop the practical knowledge expected of a junior Microsoft Systems Administrator while strengthening understanding of the technologies that support enterprise identity, hybrid environments, and security-aware operations.

Modern Microsoft environments are built through the interaction of:

- Windows Server
- Active Directory
- Microsoft Entra ID
- Microsoft 365
- Microsoft Azure
- PowerShell
- Security and monitoring solutions

This repository focuses on understanding how these technologies operate together rather than learning each technology independently.

# Laboratory Methodology

Every laboratory follows the same professional workflow.

## Planning

Define:

- Administrative scenario
- Objectives
- Environment requirements

## Implementation

Perform:

- Configuration
- Administration tasks
- System changes

## Validation

Confirm:

- Expected behaviour
- Successful configuration
- System state

## Troubleshooting

Investigate:

- Errors
- Misconfiguration
- Unexpected behaviour

## Evidence Collection

Document:

- Commands
- PowerShell outputs
- Screenshots where appropriate
- Configuration results

## Documentation

Record:

- Technical process
- Administrative reasoning
- Lessons learned

# Evidence-Based Administration Approach

This repository follows an evidence-based administration methodology.

Each laboratory aims to demonstrate:

- What was configured
- Why the configuration was required
- How success was validated
- What technical conclusions were reached

PowerShell is prioritised because it provides:

- Repeatable administration
- Auditable changes
- Structured evidence collection
- Automation potential

This reflects modern Microsoft administration practices.
